#+title: reMarkable Wiki

* Requirements
- Separate repository and maintained package for Wikipedia search/PDF reading.
- Reading-first product and announcement: provide the missing connection from
  desired content to a PDF in the native reader, rather than turn the e-reader
  into a browser. Keep reading/highlighting/annotation in the existing reader.
- Search and PDF generation use Wikipedia's public services directly from the
  tablet. No dependency on md-server, API keys, desktop or reMarkable cloud API.
- Search box, readable results, direct Download action, honest progress/errors.
- Submit only with Search/Enter. Typing, keyboard visibility and language edits
  must not hide or clear the last results. Keep results until a successful new
  search replaces them; failed/cancelled/stale responses leave them intact.
- English default and Hebrew option; remember language, provide touch keyboard.
- Import through the editor's existing DocumentImporter. Do not write library
  metadata, modify existing documents, patch firmware, or restart per download.
- Configurable existing destination folder, remembered across app launches;
  default My files. Folder changes affect new downloads only. Use native import
  with the folder ID, not filesystem moves or library metadata writes.
- Show a prominent download/import status panel with article and progress.
  After matching native success, offer Open PDF for that exact imported document.
- New PDFs follow normal device sync policy; this is not a
  cloud-exclusion feature. No claims of offline search or local PDF rendering.
- AppLoad entry, self-contained app payload, preserve all other installed apps.
- Pro first; responsive layout for Move, but qualify/install Move independently.
